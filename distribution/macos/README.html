Otter (otter-net) @VERSION@ - @CHANNEL@

otter-net is the native implementation of the Otter programming language: one otter-net command that needs nothing else installed. This is an unsigned @CHANNEL@, not an Otter release. It runs the Otter 1.0.1 language, so otter-net --version prints Otter 1.0.1.

It installs into /usr/local/lib/otter-net/@VERSION@ and links /usr/local/bin/otter-net to it. It does not install or change an otter command: if you have the released Otter (otterPS), otter still runs it. An older otter-net is replaced. A /usr/local/bin/otter-net that is not otter-net's own link stops the installation and is left untouched.

Open a new terminal afterwards and type otter-net --version.

To uninstall: sudo /usr/local/lib/otter-net/@VERSION@/uninstall.sh
